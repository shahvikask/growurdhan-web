# Contributing

This is a static site. Prefer a small HTML/CSS change over a new framework.

1. Keep the cream / stone palette and Cinzel + Plus Jakarta Sans.
2. Keep dummy names on product screens.
3. Use `http://growurdhan.com` as the canonical origin.
4. Do not add a waitlist form or an APK.
5. If you add a page, list it in `sitemap.xml` and `.github/workflows/pages.yml`.

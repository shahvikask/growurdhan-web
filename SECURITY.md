# Security

GrowUrDhan’s product rule: financial data should not leave the device.

## Website

growurdhan.com is a static marketing site. It collects no email, phone number or waitlist. Report website issues by opening a GitHub issue on this repository.

## App data

CAS parsing, vault encryption and backups are documented at http://growurdhan.com/security/ and http://growurdhan.com/privacy/.

## Secrets

This repository must not contain Play Console keys, Keystore passwords or customer statements.

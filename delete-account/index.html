Delete account

There is no GrowUrDhan login and no cloud user id to erase.

  1. On the phone, clear the app’s storage (Android Settings → Apps → GrowUrDhan → Storage → Clear data), or uninstall the app.
  2. Delete any encrypted backup files you saved in a folder you chose.
  3. A Play purchase, if you made one, is managed in Google Play. Clearing app data does not by itself refund a licence.

Because statements are not uploaded to a GrowUrDhan server, there is no server copy of your books for us to delete.
